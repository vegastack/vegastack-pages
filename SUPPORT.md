# Support

VegaStack Pages is an early open-source project. Use GitHub issues for public support requests, reproducible bugs, feature requests, and documentation gaps:

```text
https://github.com/vegastack/vegastack-pages/issues
```

Before opening an issue:

- Check [README.md](README.md), [CONTRIBUTING.md](CONTRIBUTING.md), and
  [docs/README.md](docs/README.md).
- Include your deployment mode: local Node, Docker/Node, Cloudflare, managed,
  or CLI-only.
- Include the version, tag, or commit you are running.
- Redact tokens, private tenant data, database contents, and private URLs.

For suspected vulnerabilities, do not open a public issue. Follow
[SECURITY.md](SECURITY.md).
